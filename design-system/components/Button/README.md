# Button

Botones de acción de SoyFuerte: principal en `red`, secundario con borde `white` y botón flotante de WhatsApp.

- **Principal (`sf-btn sf-btn-primary`)**: la acción que convierte, casi siempre "Escríbele a Alejo" o "Quiero este plan". Uno solo dominante por pantalla. Hover con `glow-red`, presionado en `red-deep`.
- **Secundario (`sf-btn sf-btn-secondary`)**: acciones de navegación ("Ver planes"). Hover en `orange`.
- **WhatsApp flotante (`sf-btn sf-btn-wa`)**: círculo de 56px abajo a la derecha en todas las páginas, con el ícono de WhatsApp en `white`.

Texto siempre en MAYÚSCULAS con verbo, estilo `button`. Foco visible con contorno `orange`. El consumidor pone el enlace (`wa.me` con mensaje prellenado) y el ícono.
