# PlanCard

Tarjeta de plan mensual con nombre, frecuencia, precio, lo que incluye y el botón de WhatsApp.

Estructura: `sf-eyebrow` con la frecuencia ("2 días a la semana"), `sf-card-title` con el nombre del plan, `sf-price` con el precio y "/ mes", lista `sf-list` con lo que incluye (rutinas para entrenar solo, seguimiento por WhatsApp, sesiones al mes) y un `sf-btn-primary` "Quiero este plan". El plan Constancia va destacado con `sf-card-featured` (borde `red`) y la etiqueta `sf-badge` "La más elegida". Los precios cambian con el interruptor presencial/virtual; el consumidor pone los datos desde su archivo de planes.
